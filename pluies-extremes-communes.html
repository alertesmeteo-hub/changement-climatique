Statistiques nationales

Données : calculées à partir des sorties brutes du modèle ALADIN63 (Météo-France/CNRM, trajectoire TRACC-2023), moyennées sur les ~20 ans de chaque horizon puis affectées à chaque commune par le point de grille le plus proche (résolution ~8 km — plusieurs communes voisines peuvent partager la même valeur). Contours communaux : france-geojson (IGN Admin Express, Licence Ouverte Etalab 2.0), simplifiés pour l'affichage. Cette vue est complémentaire au module Pluies extrêmes à l'échelle régionale — détails sur la page Méthode.
